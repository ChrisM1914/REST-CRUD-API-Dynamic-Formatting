# Reflections: REST CRUD API Dynamic Formatting

This assignment taught me how to build a tiny RESTful API to GET data from a Python back end. I learned and got to practice how to use CRUD endpoints (List, Get One, Create, Update, and Delete), status codes (201, 204, 400, 404), and virtual environments. I also learned how to add an HTML route, that a URL is part of an API, and highlight entries based on rating criteria.

I was surprised with the amount of coding needed for a working API. I thought a large amount of code may be needed, and I am sure it may depend on the size of the project. The @app.route connects a function to a URL and I learned previously how jsonify can turn a Python dictionary into JSON. I liked learning how JSON data could be turned into a more aesthetically pleasing format. For me this highlighted the difference between providing data and being able to incorporate it into a presentation.

I want to learn more about how I would build and utilize a real database on the backend to house the data and help with information management.
